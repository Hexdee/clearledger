# Updated project description

ClearLedger turns buyer-confirmed invoices into programmable real-world financing positions that compliant liquidity can fund and settle on-chain. A verified supplier records the invoice terms and evidence commitment, a verified buyer confirms the obligation, and an eligible liquidity provider advances funds through a governed pool. Cleanverse CVI verifies suppliers, buyers, and funders from the issuance stage; CVA is the policy-controlled asset used for both financing and repayment; and CCP exposes a pool-level eligibility decision before a transaction is submitted. The Solidity contract prevents premature financing and records the complete lifecycle for auditability, while personal identity data remains outside public contract state. ClearLedger demonstrates both an approved financing path and an ineligible wallet being blocked before value moves, creating a practical foundation for institutional invoice-finance pilots.
